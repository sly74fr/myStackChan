# myStackChan

Welcome to my desk robot experiments with [M5StackChan](https://docs.m5stack.com/en/StackChan).

Here is the stack I use:
- `Arduino IDE 2.3.8`, with:
  - `M5Stack board plugin 3.3.8`
  - `M5Unified library 0.2.18`
  - `M5GFX library 0.2.25`
- `pixi 0.62.0` for everything Python;
- `tio 3.9` for everything serial;
- `SubEthaEdit 5.2.4` for everything text;
- `macOS` for everything else !

No AI was (ab)used during those experiments.

PR warmly welcomed ☺️
